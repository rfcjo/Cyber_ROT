# 🛡️ محاكي الاستثمار السيبراني (Cyber_ROT)

نظام ذكي لمحاكاة الهجمات السيبرانية وحساب الخسائر والعائد على الاستثمار (ROI) للشبكات

تم تصميم وتطوير هذا النظام كجزء من التطبيقات العملية المتقدمة في قسم تقنيات هندسة الذكاء الاصطناعي - الجامعة التقنية الوسطى، ليكون أداة ربط بين القرارات الإدارية والمخاطر التقنية.

---

## 👨‍💻 المطور
* المهندس: جعفر حسن حميد رشيد

---

## 🎯 فكرة المشروع
يهدف Cyber_ROT إلى مساعدة صناع القرار في فهم القيمة المالية للحماية السيبرانية. بدلاً من الاعتماد على التخمين، يستخدم النظام "توأماً رقمياً" (Digital Twin) لشبكة مؤسسة تجارية، ويطلق خوارزمية ذكاء اصطناعي (AI Hacker) لاختراقها واحتساب الخسائر المحتملة بالدولار، ثم يقارنها بتكلفة خطط الحماية المختلفة لاستخراج العائد على الاستثمار (ROI).

## ⚙️ المكونات التقنية للنظام

1. عقل الذكاء الاصطناعي (AI Hacker):
   * خوارزمية جشعة (Greedy Algorithm) مكتوبة بلغة Python.
   * تحلل الأهداف المتاحة في الشبكة، تتجنب الأجهزة المخترقة سابقاً، وتختار المسار الذي يحقق أعلى ضرر مالي.
2. محرك المحاكاة (Simulation Engine):
   * مبني باستخدام إطار العمل السريع FastAPI.
   * يعالج توجيهات الذكاء الاصطناعي، ويحسب التكاليف والأرباح المحفوظة بشكل ديناميكي (Live API).
3. لوحة القيادة البصرية (Dashboard):
   * واجهة تفاعلية (Frontend) تعرض السيناريوهات الثلاثة: (بدون حماية، فصل الشبكة، حماية الأجهزة الحرجة).
   * تقدم أرقاماً واضحة وملونة لتسهيل اتخاذ القرار الإداري.

## 🚀 تقنيات التطوير المستخدمة (Tech Stack)
* Backend: Python 3, FastAPI, Uvicorn, NetworkX
* Frontend: HTML, CSS
* Deployment: Localtunnel, GitHub

## 💡 سيناريوهات الحماية المدروسة
1. بدون حماية: هجوم ذكاء اصطناعي كامل، يمثل أسوأ خسارة ممكنة للمؤسسة.
2. فصل الشبكة (Segmentation): تقليل مساحات الهجوم بتكلفة حماية متوسطة.
3. فصل + حماية الأجهزة الحرجة: الاستثمار الأمثل للحماية مع تحقيق أعلى عائد مالي للمؤسسة.
